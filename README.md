# MEPHI Session Project 2026

## Описание проекта

Лабораторная работа по администрированию и безопасности Linux.

Среда выполнения:
- Fedora Workstation 44
- Oracle VirtualBox 7.2.20
- Hostname: mephi-2026.domain.local

## Выполненные задания

### 1. Настройка сети
Настроено динамическое получение IP-адреса через DHCP.
Проверена связь с 8.8.8.8.

### 2. Управление пакетами
Установлены nginx и libcap-ng-utils через DNF.
Утилита tcpdump установлена из локального RPM-пакета.

### 3. Файловая система
Создан дополнительный раздел /dev/sdb1.
Файловая система: ext4.
Метка: MEPHI_WEB.
Настроено автоматическое монтирование в /mephi-web.

### 4. Управление службами
Запущен веб-сервер nginx.
Настроен его автоматический запуск.
Сохранены сообщения системного журнала.

### 5. Управление доступом
Настроены группы разработчиков и кураторов.
Для каталога /data/mephi-2026 применены POSIX ACL и SetGID.
Утилите tcpdump назначены Linux Capabilities.
Настроен SELinux в режиме Enforcing.
Веб-сервер использует каталог /mephi-web.

### 6. Безопасность пользователей
Ограничен консольный вход для группы curators через PAM.
Установлена смена паролей каждые 90 дней.
Минимальная длина пароля — 12 символов.

### 7. Веб-страница
Создан файл /mephi-web/index.html.

Содержимое:
Hello from Student: 375706

### 8. Сохранение результатов
Сохранены результаты выполнения команд в файлах .out,
системные настройки и подтверждающий скриншот.

## Безопасность публикации

Файлы passwd, group и fstab представлены учебными выдержками.
В файле shadow реальные хеши паролей заменены на REDACTED.
Конфиденциальные данные не предназначены для публикации.
